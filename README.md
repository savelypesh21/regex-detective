Regex-детектив
Описание игры
«Regex-детектив» — консольная игра в жанре детективного расследования, в которой игрок использует регулярные выражения Python для решения различных заданий и раскрытия дела.

Правила игры
1. Игрок проходит несколько глав расследования.
2. В каждой главе представлены задания, примеры входных данных и описание задачи.
3. Игрок самостоятельно вводит регулярное выражение.
4. Программа проверяет введённый шаблон на предоставленных данных с помощью соответствующих методов модуля re.
5. За правильное решение игрок проходит раунд и продвигается дальше.
6. Цель игры — успешно завершить все раунды расследования.

Запуск игры
Для запуска установите необходимые зависимости:

pip install -r requirements.txt
Запуск консольной версии:

python main.py
Участники проекта
• Пешехонов Савелий — разработка главы «Бюро пропусков» (passes.py).
• Бакиров Орозбек — разработка главы «Архив переписки» (archive.py).

Структура проекта
• main.py — точка входа и запуск игры.
• round_base.py — базовая логика проверки регулярных выражений.
• rounds.py — объединение глав и проверка раундов.
• passes.py — глава «Бюро пропусков».
• archive.py — глава «Архив переписки».
• test_rounds.py — автоматические тесты.
• requirements.txt — список зависимостей проекта.
